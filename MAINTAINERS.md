# Maintainers

FlowGPU is maintained in public. The current maintainer is:

- **@KIOSHIROI** — repository owner and release manager.

## Maintainer responsibilities

- Keep `main` green on Python 3.11–3.13 and keep the wheel build passing.
- Triage issues and pull requests; label bugs, documentation and good-first-issues.
- Review dependency and security updates (Dependabot, advisories).
- Enforce the public/private boundary: no competition submissions, organizer
  task packages, private evidence, research data, personal host paths or tokens
  may enter this repository. Run `python tools/publish_guard.py` before releases.
- Keep the README, docs, CHANGELOG and release notes accurate.
- Cut releases only from a green `main`, with a matching `vX.Y.Z` tag.

## Becoming a maintainer

Sustained, high-quality contributions and review participation are the path to
maintainership. There is no CLA; contributions are accepted under the MIT
license.
