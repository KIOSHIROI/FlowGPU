# Support

FlowGPU is a volunteer-maintained prototype. There is no support SLA.

- **Questions / ideas / usage:** open a GitHub issue and include the version
  (`flowgpu --version`), OS, Python version and a minimal `.fgpu` program.
- **Bugs:** use the bug report template; include the exact command and, if
  relevant, whether the failure is on the reference backend or `--run-gpu`.
- **Security:** do not open a public issue; follow [SECURITY.md](SECURITY.md).
- **Contributions:** see [CONTRIBUTING.md](CONTRIBUTING.md).

Before filing, check [Getting started](docs/getting-started.md),
[FAQ](docs/faq.md) and [Troubleshooting](docs/troubleshooting.md).
